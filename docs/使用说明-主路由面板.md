# 小米 AX3000E 主路由完整版面板 —— 使用说明

## 文件清单
- `router_monitor_ax3000e.py`  主路由完整版面板（含端口转发/QoS/DHCP/防火墙，已修复全部已知 bug）
- （原 `router_monitor_ax3000e.py.bak-*`  覆盖前的 AP 版备份）

## 硬件信息
真实硬件为**小米 AX3000E**（ARMv7 / 4.4.60 / Dropbear 2017.75）。
所有命令、路径、接口名都已按 AX3000E 实测校准，可直接用。

## 两种模式用哪个脚本
| 模式 | 用哪个 | HOST 默认 | 功能 |
|---|---|---|---|
| **主路由模式**（断开上级路由、自己拨号） | `router_monitor_ax3000e.py` | 192.168.31.1 | 端口转发/QoS/DHCP静态绑定/防火墙 |
| **中继/AP 模式**（接上级路由） | 仓库 `panel/router_monitor_ap.py` | 无默认，填实际 IP（AP 模式由上级 DHCP 分配） | 仅 WiFi+DNS 去广告 |

⚠️ 当前设备处于**中继(AP)模式**，主路由版面板能连、能看基础监控，但端口转发/QoS/静态绑定是**空的**——因为这些功能由上级路由管理。想用完整功能需把设备切回主路由模式。

## 启动命令
```powershell
cd <仓库目录>\panel
python router_monitor_ax3000e.py --host 192.168.31.1
```
若换了 IP，用 `--host <实际IP>`、`--port 22`、`--user root`、`--passwd <密码>`、`--web 8787` 覆盖。

## SSH 连接参数
- 账号：`root`
- 密码：`<你的密码>`（或设环境变量 `ROUTER_PASSWD`）
- 端口：22
- 注意：Dropbear 是 2017.75 老版本，需 `disabled_algorithms={'keys': ['rsa-sha2-256','rsa-sha2-512']}` 才能握手（脚本已内置）

## 本版已修复的 bug（相对原版）
1. **collect 合并**：5 次 SSH → 1 次（性能 +80%，WAN 口用 eth1.4）
2. **WiFi 读取合并**：12 次 → 1 次（`uci show wireless` 本地解析）
3. **wifi_channel**：`set_channel`（函数名错，必失败）→ 直接 `iwconfig channel`
4. **LED 控制**：硬编码 sysfs → 官方 `led_ctl` + `xiaoqiang.common.XLED`
5. **去广告读取**：只认 hagezi → 兼容 hagezi 或 anti-AD（当前设备用 anti-AD 100552 条）
6. **wifi 死代码**：修复替换错位导致的不可达代码（原 wifi 块被移到 return 后）

## 设备基础信息（实测）
- 网段：当前 192.168.2.x（AP），主路由默认 192.168.31.1
- WiFi：2.4G 接口=`wl1`(wifi0/11axg)，5G 接口=`wl0`(wifi1/11axa)
- 固件已装：SSH 解锁、DNS 8 上游、anti-AD 去广告、抖音定向、禁IPv6、auto_ssh 自愈（由 firewall include + cron 双保险）
- 已停用（降负载）：wan_check_status、smartcontroller（不影响米家核心功能）
