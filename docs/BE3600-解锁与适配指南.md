# 小米 BE3600 2.5G 解锁与预适配指南

> 状态：**预适配**（解锁方法已整理，套件移植待实机验证）。
> 来源：恩山论坛 thread-8459209（降级法，openwrt_qca9533）/ thread-8422440（直接开 SSH，gngyl）/ hugevip.github.io 刷机教程；2026-08-29 存档。
> 本套件（panel/ + router/auto_ssh.sh + deploy/）设计上与设备无关的部分可直接复用，差异点见文末适配清单。
> 实机校准：解锁后运行只读探针 `python deploy/device_probe.py <IP>`，一次性产出设备画像报告，逐项对照下方清单。

## 硬件速查

| 项目 | 参数 |
|---|---|
| SoC | 高通 IPQ5312（256MB RAM，128MB NAND） |
| WiFi | Wi-Fi 7，160MHz（320MHz 需 6GHz，国内未开放） |
| 网口 | 2.5G WAN + 千兆 LAN（2.5G 版） |
| 分区 | 双系统分区（OS1/OS2 互为备份），uboot 在 mtd14，分区表在 mtd2 |

> 只需 DNS/SSH/去广告的话，保留原厂固件 + 本套件即可，不必刷 OpenWrt（高通平台 OpenWrt 适配不如联发科成熟）。

## 版本兼容矩阵

| 固件版本 | 能否直接开 SSH | 方法 |
|---|---|---|
| v1.0.68（出厂） | ✅ | 方法 A：curl 注入 或 xmir-patcher |
| v1.0.80 / v1.0.81 | ✅ | 方法 A |
| v1.0.87（最新） | ❌ | 先方法 B 降级到 v1.0.81，再方法 A |

v1.0.87 修复了 start_binding 注入并关闭串口，无法直接开或直接降级。

## 方法 A：v1.0.80/81 直接开 SSH

浏览器登录管理页，从地址栏取 `;stok=` 后的字符串，依次执行（替换 `<IP>`/`<STOK>`，建议 Git Bash，Windows cmd 可能有编码问题报 1541）：

```bash
curl -X POST "http://<IP>/cgi-bin/luci/;stok=<STOK>/api/xqsystem/start_binding" -d "uid=1234&key=1234'%0Anvram%20set%20ssh_en%3D1'"
curl -X POST "http://<IP>/cgi-bin/luci/;stok=<STOK>/api/xqsystem/start_binding" -d "uid=1234&key=1234'%0Anvram%20commit'"
curl -X POST "http://<IP>/cgi-bin/luci/;stok=<STOK>/api/xqsystem/start_binding" -d "uid=1234&key=1234'%0Ased%20-i%20's%2Fchannel%3D.*%2Fchannel%3D%22debug%22%2Fg'%20%2Fetc%2Finit.d%2Fdropbear'"
curl -X POST "http://<IP>/cgi-bin/luci/;stok=<STOK>/api/xqsystem/start_binding" -d "uid=1234&key=1234'%0A%2Fetc%2Finit.d%2Fdropbear%20start'"
```

注意：第 3 条的 sed 修改**重启会复原**，必须靠自启动脚本持久化（本套件的三层自愈体系正是干这个的）。
替代工具：[xmir-patcher](https://github.com/openwrt-xiaomi/xmir-patcher)（先 1 设 IP → 2 开 SSH）；部分批次 telnet 23 端口默认开着，可作备用通道。

## 方法 B：v1.0.87 断电破坏双分区降级（中风险）

前置：MiWiFi 官方修复工具 + [v1.0.81 固件](https://miuirom.org/miwifi/xiaomi-router-be3600-2-5g) + v1.0.87 固件（同版本升级用）+ 电脑网线直连 LAN。

1. **破坏 OS2**：进恢复模式（断电按住 reset 插电）→ 修复工具刷 v1.0.87 → 进度条走完后**等约 12 秒断电**
2. **破坏 OS1**：立即再进恢复模式 → 再刷 v1.0.87 → 进度条走完后**等约 5 秒断电**（顺序不能反）
3. **确认**：通电后路由器应不断重启（灯循环闪）；正常启动说明时机不对，回到第 1 步重试
4. **降级**：恢复模式刷 v1.0.81，此时修复工具不再校验版本号
5. **开 SSH + 立即关自动升级**（否则联网自动升回 1.0.87，前功尽弃）

断电时机（12s/5s）是原作者接 TTL 实测的参考值，±2-3 秒摸索。变砖恢复：只要 uboot 没坏，官方修复工具都能救回（可能需刷 2 次）。

## 方法 C：刷 OpenWrt（不推荐，仅存档）

SSH 通了之后可刷大分区表（mtd2）+ uboot（mtd14）再进 uboot 刷机页刷 OpenWrt。**高风险**：mtd2/mtd14 刷错或断电即变砖且官方工具救不回。只需 DNS/去广告请勿走此路。完整教程见来源链接。
