# AX3000E 路由器 SSH 自救手册（2026-08-27 定稿）

## 设备与凭据
| 项 | 值 |
|---|---|
| 型号 | 小米 AX3000E（RN07，显示名"小米路由器AX3000E"） |
| 固件 | 1.0.24 **(禁止升级！升级=解锁全部报废)** |
| 角色 | 中继/AP 模式，挂上级 K2P (192.168.2.1) 之后 |
| MAC | `<ROUTER-MAC>` |
| SSH | root / admin · dropbear 2017.75（老算法，需兼容参数见下） |
| ⚠️ IP 会漂 | 重启后 DHCP 可能换地址（历史：.100→.105→.106）。失联先按 MAC 找 |

按 MAC 找 IP（PowerShell）：
```powershell
ping 192.168.2.x -n 1   # 对网段内几台先 ping 通；然后
arp -a | findstr 58-ea
```

SSH 连接（老 dropbear 需降级握手）：
```powershell
ssh -oHostKeyAlgorithms=+ssh-rsa -oPubkeyAcceptedAlgorithms=+ssh-rsa root@<路由器IP>
# python/paramiko 记得加: disabled_algorithms={'keys': ['rsa-sha2-256','rsa-sha2-512']}
```

## 现有自愈体系（2026-08-27 起）
1. **防火墙钩子** `/etc/config/firewall → auto_ssh.include` → 每次防火墙重载执行 `/data/auto_ssh/auto_ssh.sh`
2. **cron 兜底**（每分钟一次检查拉活）：`* * * * * /bin/sh /data/auto_ssh/auto_ssh.sh`
   （注意：固件偶尔会整体重写 crontab 把这行清掉——发现没了就重加一行即可）
3. v4 脚本特性：毫秒级防重复（marker）、广告列表只用本地缓存+48小时刷新、后台 10 分钟重试兜底

日志排查：`grep auto_ssh /tmp/messages`

## 万一 SSH 又死了（按顺序自救）
**第 0 步**：先确认不是 IP 变了（上面按 MAC 找）；再试 ping。整机 5 分钟内自动恢复属正常重启。

**第 1 步·远程重新解锁（不丢配置）**
1) 浏览器登录 `http://<路由器IP>` → 地址栏复制 `stok=` 后那串
2) 替换下面命令里的 stok 和 IP 后逐条执行（原始漏洞接口是 start_binding）：
```powershell
$S="<你的stok>"; $B="http://<路由器IP>/cgi-bin/luci/;stok=$S/api/xqsystem/start_binding"
curl.exe -X POST $B -d "uid=1234&key=1234'%0Anvram%20set%20ssh_en%3D1'"
curl.exe -X POST $B -d "uid=1234&key=1234'%0Anvram%20commit'"
curl.exe -X POST $B -d "uid=1234&key=1234'%0Ased%20-i%20's%2Fchannel%3D.*%2Fchannel%3D%22debug%22%2Fg'%20%2Fetc%2Finit.d%2Fdropbear'"
curl.exe -X POST $B -d "uid=1234&key=1234'%0A%2Fetc%2Finit.d%2Fdropbear%20start'"
```
3) `Test-NetConnection <路由器IP> -Port 22` 应为 True，之后照常登录。
⚠️ `arn_switch` 接口在这台机器上是假接口（code:0 但不执行），别用。

**第 2 步**：能进管理页时切换任意防火墙相关开关（UPnP/DMZ/访客网络 关→开）也能触发自愈脚本。

**第 3 步（最后手段）**：官方修复工具刷机 = 全部清空重来，之后运行桌面《一键部署》并从本档案恢复各文件到 `/data/`。

完整备份存于本文件夹内同名文件 + `Desktop\路由器配置存档-20260827\`。

验证命令：
```
nslookup ad.doubleclick.net <路由器IP>   # 应回 0.0.0.0
nslookup www.baidu.com <路由器IP>        # 应正常出地址
```
中继模式注意：要让全屋设备走这套去广告，需在 K2P 的 DHCP 里把 DNS 指向 `<路由器IP>`。

## 建议一步到位：在 K2P 绑定静态 IP
K2P 管理页(192.168.2.1) → DHCP/局域网设置 → 静态绑定，把 MAC `<ROUTER-MAC>` 绑死到固定地址（如 192.168.2.106）。绑完从此"失联"问题少一半，面板脚本也永不用改 IP。
